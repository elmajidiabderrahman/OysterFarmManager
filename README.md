Oyster Farm Manager v1.5.3

العربية
بيانات الدفعة تحتوي فقط على العدد الإجمالي للمحار وعدد الجيوب في كل طاولة، ولا تحتوي على نسبة نفوق. داخل كل مرحلة نمو تظهر خانة مستقلة لنسبة النفوق ويمكن تعديلها، بما في ذلك مرحلة المحار الصغير والمرحلة النهائية. تعرض النتائج المحار النافق والمتبقي بعد كل مرحلة. تم تحديث ذاكرة التخزين المؤقت للتطبيق حتى تظهر التعديلات الجديدة على iPhone.

English
Batch data contains only the total oyster count and pockets per table; it has no mortality field. Every growth stage has its own editable mortality percentage, including the small-oyster and final stages. Results show deaths and survivors at each stage. The service-worker cache version was updated so the changes appear on iPhone.

Français
Les données du lot contiennent uniquement le nombre total d’huîtres et le nombre de poches par table, sans taux de mortalité. Chaque stade possède son propre taux de mortalité modifiable, y compris le stade des petites huîtres et le stade final. Le cache a été mis à jour pour afficher les changements sur iPhone.
